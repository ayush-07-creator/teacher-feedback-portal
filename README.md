# Teacher–Student Constructive Feedback Portal

A full-stack web application designed to facilitate two-way constructive feedback between teachers and students. The platform provides role-based access, feedback management, dashboards, and database integration to support a better academic feedback process.

## Features

- Teacher and student role-based access
- Admin functionality
- Two-way constructive feedback
- Feedback submission and management
- Teacher dashboard
- Student dashboard
- Feedback analytics
- Database integration
- Responsive web interface

## Technologies Used

##  How It Works

Users access the platform according to their assigned role.
Students can provide constructive feedback to teachers.
Teachers can view and manage feedback.
Administrators can manage the platform and relevant users.
Feedback data is stored in MongoDB.
Dashboards provide an organized view of relevant information.
Feedback analytics help present feedback data in a structured way.

## Project Purpose

The project was developed as an academic project to explore how web technologies can be used to create a structured and constructive feedback system between teachers and students.

The goal is to provide a platform where feedback can be collected and managed in an organized manner, helping improve communication between students and teachers.
